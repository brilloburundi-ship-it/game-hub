# World Kingdoms LIVE

Fresh autonomous civilization and TikTok LIVE god-game. The simulation, procedural Earth-like world, economy, settlements, NPC routines, roads, territory, diplomacy, wars, conquest, camera director, viewer membership, voting and event bridge were developed independently for this project.

## Asset boundary

The project does not import the Kingdom War 2 map, code, UI, bridge, simulation or gameplay systems. It reads only these two Kingdom War 2 asset catalogs at runtime:

- `../kingdom-war-2/assets/buildings/manifest.json`
- `../kingdom-war-2/assets/minifolks/manifest.json`

Every visible building comes from the Kingdom War 2 building catalog. Every civilian, worker, merchant, colonist and soldier comes from the Kingdom War 2 MiniFolks catalog. Terrain, water, borders, roads, labels and particles are generated by this project.

## Modes

- `?mode=test` enables simulated join, chat, vote, likes, follow, share and three gift tiers.
- `?mode=live&token=...` hides test controls and accepts real TikFinity events from the independent relay.

Run `npm start` inside this folder for the desktop relay. It prints both a local URL and a LAN URL suitable for Safari, PWA installation or OBS Browser Source. The bridge defaults to port `8795` and TikFinity WebSocket `ws://127.0.0.1:21213/`.
