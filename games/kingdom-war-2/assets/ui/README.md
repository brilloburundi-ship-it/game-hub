# Royal HUD source artwork

Place the original 941×1672 transparent PNG here as `royal-hud.png` to enable the exact artwork by default for all players. The game automatically crops the supplied image into logo, resource bar, ranking, chronicle, war and interaction panels and overlays live data. Until the binary image is added, use TEST → IMPORT HUD with the original PNG. The browser remembers the image locally. PORTRAIT HUD fits the overlay to a central vertical composition. Wood remains the fifth simulated resource, rather than inventing iron income.
