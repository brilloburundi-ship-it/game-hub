# Kingdom War 3 — Survivor Siege

This project now uses the **native Kingdom War 2 runtime and renderer** as its technical/visual base: same Pixi scene, map projection, terrain pipeline, pixel building assets, MiniFolks NPCs, water and the exact four-part pixel flora atlas.

Kingdom War 3 changes only the game mode on top of that base:
- maximum two active kingdoms: champion and challenger;
- smaller bounded expansion arena;
- fortified spawn with central castle, walls, gate, stone towers and economy buildings;
- champion survives the round and receives a shield;
- queued JOIN becomes the next challenger;
- short fortification phase followed by physical siege warfare;
- existing Kingdom War 2 economy, LIVE power, individual armies, farmer mobilization and gift reinforcement systems remain available.

Kingdom War 2 remains a separate project and is not modified by Kingdom War 3.
